# Minimal application runtime notices

The application image contains Node 24.21.0 and three unmodified Alpine 3.24 runtime packages: musl 1.2.6, libgcc and libstdc++ 15.2.0. Their exact revisions and Alpine build commits are recorded in `index.json` generated from the real installed-package database. A changed upstream version or an additional package stops the build for review.

- `NODE-LICENSE` is copied at build time from the pinned official Node image's `/usr/local/LICENSE`. It includes Node's MIT license and embedded third-party notices, including OpenSSL, ICU and its bundled certificate data. [Node 24.21.0 license](https://github.com/nodejs/node/blob/v24.21.0/LICENSE).
- [musl 1.2.6 COPYRIGHT](https://git.musl-libc.org/cgit/musl/tree/COPYRIGHT?h=v1.2.6) is retained unchanged as `musl-COPYRIGHT` (SHA256 `b870108ec5e7790e9f9919064f1b9421d62d5f9b0e6c230c6adf7ea2da62e97b`). It records MIT and compatible component terms.
- The unchanged upstream `musl-1.2.6-source.tar.gz` accompanies the notices to preserve individual source-file copyright and license notices. SHA256 `d585fd3b613c66151fc3249e8ed44f77020cb5e6c1e635a616d3f9f82460512a` was cross-checked against Alpine's source SHA512 in [the recorded aports build](https://gitlab.alpinelinux.org/alpine/aports/-/blob/f5640d3a10f664c9119720c60515265d3d6f6d01/main/musl/APKBUILD). It is downloaded with checksum enforcement during the image build, never taken from an operator's machine.
- GCC's [GPLv3 text](https://github.com/gcc-mirror/gcc/blob/releases/gcc-15.2.0/COPYING3) and [Runtime Library Exception 3.1](https://github.com/gcc-mirror/gcc/blob/releases/gcc-15.2.0/COPYING.RUNTIME) are retained unchanged as `GCC-COPYING3` and `GCC-RUNTIME-EXCEPTION` (SHA256 `8ceb4b9ee5adedde47b31e975c1d90c73ad27b6b165a1dcd80c7c545eb65b903` and `9d6b43ce4d8de0c878bf16b54d8e7a10d9bd42b75178153e3af6a815bdc90f74`). The exception permits redistribution of eligible target code linked with these runtime libraries under independent terms. The native SQLite addon is built with the unmodified GCC toolchain; no compiler plugin or runtime-library modification is introduced.

Alpine's broad GCC package license metadata is preserved verbatim, separately from the runtime exception. Review the actual library contents and upstream exception rather than relabeling the package. Build recipes and patches are accessible by each recorded build commit in [Alpine aports](https://gitlab.alpinelinux.org/alpine/aports).

The image contains no BusyBox, apk executable, npm, Corepack, Yarn or Sharp/libvips binaries. Node uses its bundled certificate store; it does not require an external CA package. This notice folder is included both in the image and in the downloadable notices archive. It does not change KekBot's MIT license.
