# KekBot 0.1.0-beta.3

**[Published evaluation release — 2026-10-09](https://github.com/DangerMouseUK/kekbot/releases/tag/v0.1.0-beta.3).** Beta 3 distributes the lifecycle launcher with matching management/application source and six audited assets. Beta 1/2 tags/assets and historical reviews remain unchanged. [Beta guide](../BETA.md) · [Launcher walkthrough](../LAUNCHER.md) · [All documentation](../README.md).

## Included in this beta

- A downloadable Bash `install.sh` entry with explained install/manage menus, offline prerequisite checks and optional separately confirmed Ubuntu 24.04 setup. No repository clone is needed for the launcher path.
- All existing application source options: accepted latest stable, explicit beta releases, branches, PR heads, exact commits and audited source/image bundles. Management code is selected and reviewed independently, before it executes.
- Update, rollback, status, stop/start and retained-data uninstall through the guarded Python lifecycle engine. New installations retain the reviewed launcher; application updates do not overwrite management tools.
- A standalone `install.sh` release asset, identical to committed and archived source bytes and covered by `SHA256SUMS`. Source-only packaging includes it too. Metadata format 1 adds the optional `launcher` filename; legacy beta 1/2 bundles remain supported.
- A fixture rehearsal correction for accepted bundles: application trust is requested only when required, followed by final `APPLY`. Synthetic accepted metadata does not imply an accepted stable release.

The application workflows remain Kick automation, Discord controls, OBS alerts/widgets, YouTube queue/playback, moderation, community features and local operator tools described in the [user guide](../USER_GUIDE.md). No application dependency, SQL migration, data format or new provider capability is introduced by beta 3.

## Compatibility and upgrades

Supported distribution remains **Linux amd64 Docker image archive** or **audited source archive built with Docker**. The interactive host manager uses Bash and Python 3.10+ standard library. Windows/macOS can evaluate Linux containers using [Docker Desktop](../DOCKER_DESKTOP.md); no native executable, ARM64 package, `.deb`/`.rpm` or registry image is offered.

SQLite remains schema 3, with backup and configuration format 1. Schema 1/2 upgrade behavior is unchanged. Keep the original encryption key and an independent database/asset backup; source rebuilds have their own image identity. A downgrade does not reverse migrations.

Install the exact published beta 3 assets recorded below, following [versioned launcher verification](../LAUNCHER.md#verify-a-versioned-launcher-download) and the [beta walkthrough](../BETA.md#install-the-published-beta). Pin management with `--tool-release v0.1.0-beta.3` and the application with the same explicit `--release`, or pin `--tool-commit` and `--bundle` to this verified download. **Latest stable** continues to exclude prereleases; there is no accepted stable release.

For beta 1/2 installations, use the newly reviewed launcher and management SHA explicitly for the update, keeping that tool source available afterward. The old copied manager stays intact, and an application update does not add `/tool/install.sh` to older installations. Follow [beta update/recovery](../BETA.md#update-recover-or-remove) and [rollback](../UPDATING.md#roll-back-after-failure-or-a-bad-update). Never force Start past a failed update/rollback guard. Uninstall retains data by default; purge needs separate confirmation.
